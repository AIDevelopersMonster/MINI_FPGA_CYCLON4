# 📘 **README.md — DA Module (Cyclone IV, AD9708, Parallel DAC)**

## 🔧 **Описание проекта**

Данный модуль — простой демонстратор работы *параллельного ЦАП* (например, **AD9708**, 8-бит, до 125 MSPS).
FPGA формирует последовательность цифровых данных **0…255**, которые отправляются в ЦАП.
Выход ЦАП — это возрастающая «пила» (sawtooth wave), которую можно наблюдать на осциллографе.

Используется тактовый сигнал FPGA как:

* **DA_CLK** — синхросигнал для ЦАП
* **DA_Data[7:0]** — параллельные данные

---

## 📡 **Как работает модуль**

### ⚙️ Основная логика

Модуль содержит 8-битный счётчик:

* при каждом такте `CLK` значение `Count` увеличивается;
* когда оно достигает `255`, счётчик обнуляется;
* одновременно значение передается в `DA_Data`.

Итого: на выходе формируется периодический сигнал (0 → 255 → 0 → …).

### 🔄 Формируемый сигнал

На осциллографе это будет **пилообразный сигнал** после выхода ЦАП и фильтрации.

---

## 📜 **Код модуля**

```verilog
module DA
(
    CLK, RSTn, DA_CLK, DA_Data
);

   input CLK;
   input RSTn;	
   output DA_CLK; 
   output reg [7:0]DA_Data; 

   reg [7:0]Count;  

   assign DA_CLK = CLK ;		

   always @( posedge CLK or negedge RSTn )
        if( !RSTn )
            Count <= 0;
        else if ( Count == 'd255 )
            begin
                Count <= 0; 
                DA_Data <= Count[7:0] ;  
            end 
        else
            begin
                Count <= Count + 1'b1;
                DA_Data <= Count[7:0] ;  
            end

endmodule
```

---

## 🧪 **Как протестировать**

1. Подключить выходы `DA_Data[7:0]` и `DA_CLK` к входам ЦАП-платы (например AD9708).
2. Дать питание 5V и опорное напряжение ЦАП.
3. На осциллографе наблюдать:

   * **пилообразное напряжение** после выходного фильтра,
   * или **ступенчатый сигнал** напрямую с токового выхода ЦАП.

---

## 🧩 **Под какие платы подходит**

* Waveshare AD/DA Board (AD9708 + AD9280)
* Любая AD9708 breakout-плата
* Любой 8-битный параллельный ЦАП с latch-input по фронту такта

## 📈 **Что можно улучшить**

* добавить LUT-генератор синуса;
* добавить выбор режима: синус / треугольник / saw / noise;
* увеличить разрядность (при замене ЦАП);
* добавить PLL чтобы увеличить частоту дискретизации.
