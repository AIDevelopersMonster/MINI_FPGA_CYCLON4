# **DDS — Direct Digital Synthesis на FPGA Cyclone IV (MINI_FPGA_CYCLONE4)**

Проект демонстрирует реализацию **цифрового синтезатора частоты (DDS)** на базе FPGA **Cyclone IV**, включая:

* регулировку частоты с помощью кнопок KEY0 / KEY1
* переключение формы сигнала (Sin / Square / Sawtooth)
* 12-битный фазовый аккумулятор
* таблицы ROM для синуса, меандра и пилы
* вывод результата через цифровой интерфейс в ЦАП (DA-плата)

---

## 📌 **1. Назначение проекта**

DDS (Direct Digital Synthesis) — это метод цифровой генерации периодических сигналов. Он обладает преимуществами:

* высокая частотная стабильность
* точность настройки
* возможность генерировать разные формы сигнала
* простая реализация в ПЛИС

В проекте реализовано DDS-ядро с регулируемой частотой и тремя формами сигнала.

## ⏱️ **3. Принцип работы DDS**

### **Фаза**

Внутри используется **12-битный фазовый аккумулятор Cnt**:

```
Cnt = Cnt + KW
```

где **KW** — управляющее слово частоты (*frequency word*).

### **Формула частоты DDS**

[
f_{out} = \frac{KW}{4096} \cdot f_{clk}
]

Чем больше KW → тем быстрее рост фазы → выше частота выходного сигнала.

### **Форма волны**

Значение фазы (Cnt) используется как адрес в ROM-таблицах:

* `dds_sin_rom`
* `dds_square_rom`
* `dds_sawtooth_rom`

По состоянию переключателей SW1–SW3 выбирается одна из таблиц.

---

## 🎛️ **4. Управление**

| Элемент          | Назначение                  |
| ---------------- | --------------------------- |
| **SW0**          | Сброс RSTn (активный 0)     |
| **KEY0**         | Увеличить частоту (KW + 1)  |
| **KEY1**         | Уменьшить частоту (KW – 1)  |
| **SW1**          | Выбрать синус               |
| **SW2**          | Выбрать меандр              |
| **SW3**          | Выбрать пилообразный сигнал |
| **DA_CLK**       | Такт в ЦАП = системный такт |
| **DA_Data[7:0]** | 8-битные выборки сигнала    |

---

## 🧩 **5. Описание модулей**

### **1) `frequency_adjust_module`**

Формирует управляющее слово частоты KW (1…10, циклически).
Использует антидребезговый модуль `Jitter_Elimination_module`.

---

### **2) `choose_wave_module`**

Основной блок DDS:

* содержит фазовый аккумулятор
* генерирует адрес ROM
* по переключателям выбирает одну из трёх форм волн

---

### **3) `dds_*_rom`**

ROM-таблицы, сгенерированные MegaWizard:

* `dds_sin_rom` — синус
* `dds_square_rom` — меандр
* `dds_sawtooth_rom` — пила

Объём: **4096 × 8 бит**.

---

### **4) `dac_module`**

Минимальный интерфейс в ЦАП:

* DA_CLK = CLK
* DA_Data = Wave_Data

---

### **5) `DDS` (топ-модуль)**

Объединяет все предыдущие блоки.
