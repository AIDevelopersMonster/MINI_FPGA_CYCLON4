# **MINI_FPGA_CycloneIV — Проект АЦП + Индикация (AD + AD_Data + Digitron_NumDisplay)**

Этот проект реализует полный цикл работы с внешним АЦП на базе FPGA **Cyclone IV** (плата MINI_FPGA):
от формирования управляющих сигналов для чипа ADC → до получения 10-битных данных → и отображения результата на шестиразрядном семисегментном индикаторе.

Проект состоит из трёх основных модулей:

1. **`AD`** – верхнеуровневый модуль проекта.
2. **`AD_Data`** – модуль управления АЦП (формирование AD_CSn, AD_Clk, AD_Address, приём данных).
3. **`Digitron_NumDisplay`** – модуль отображения полученных данных на 7-сегментных индикаторах.

---

# **1. Архитектура проекта**

```
        +------------------+
CLK --->|                  |
RSTn -->|       AD         |----> AD_CSn
AD_EOC->|                  |----> AD_Clk
DataIn->|                  |----> AD_Address
        |                  |
        |  +-----------+   |----> Data_Out[9:0]
        |  | AD_Data   |   |----> CS_Valid_Sig
        |  +-----------+   |
        |                  |----> Digitron_Out[7:0]
        |  +----------------+
        |  | Digitron_Display
        |  +----------------+
        +------------------+
```

---

# **2. Модуль AD (верхний уровень)**

### Функции:

* Управляет процессом выборки данных АЦП.
* Инстанцирует модуль `AD_Data` для формирования сигнала CS, I/O CLOCK и выбора канала.
* Передаёт полученные данные в модуль отображения `Digitron_NumDisplay`.
* Использует PLL для генерации 100 кГц тактовой частоты.

### Основные выходы:

* **AD_CSn**, **AD_Clk**, **AD_Address** — линии управления АЦП.
* **Digitron_Out**, **DigitronCS_Out** — управление индикаторами.

---

# **3. Модуль AD_Data — ядро работы с АЦП**

Этот модуль реализует **полный протокол общения с внешним ADC**:

### Что делает:

✔ Опускает AD_CSn для начала цикла выборки.
✔ Выдерживает тайминг **tsu(cs)** перед началом тактирования.
✔ Формирует синхронный I/O CLOCK (AD_Clk).
✔ Последовательно принимает **10 бит данных AD_DigData_In**.
✔ Выставляет биты адреса AD_Address в нужные моменты.
✔ Поднимает AD_CSn и ожидает время конверсии (21 мкс).
✔ Выдаёт **Data_Out[9:0]** и строб валидности **CS_Valid_Sig**.

### Внутренняя реализация:

* аппаратная state-machine на счётчике `i`.
* 4 аппаратных таймера: Cnt1, Cnt2, Cnt3, Cnt4 (синхронизация временной диаграммы ADC).
* Поддержка каналов AIN5, Verf+, (Verf+ + Verf-) / 2.

---

# **4. Модуль Digitron_NumDisplay — индикация данных**

Отображает полученные от АЦП 10-битные данные как шестиразрядное HEX-число:

```
Hex_SixNum = {14'b0, Data[9:0]}
```

то есть отображаемое значение — это:

```
0000 XX XX XX (шесть разрядов)
```

### Функции:

* Разбивает 24-битное число на 6 тетрад.
* Циклически включает каждый индикатор (мультиплексирование).
* Для каждой тетрады выводит соответствующий HEX-шаблон сегментов.
* Работа стабильная, без мерцания, с корректным сканированием.

---

# **5. Тайминги и частоты**

Проект предполагает системный такт **50 МГц**.

| Генератор | Назначение                  | Значение      |
| --------- | --------------------------- | ------------- |
| pll_100K  | тактирование логики AD_Data | 100 кГц       |
| Cnt1      | формирование AD_Clk         | 520 нс период |
| Cnt2      | tsu(cs)                     | 1.44 мкс      |
| Cnt4      | conversion time             | 21 мкс        |

Все цифры соответствуют даташиту ADC и подтверждены анализом SignalTap.

# **6. Входы/выходы проекта**

### **Входы**

| Сигнал          | Описание                              |
| --------------- | ------------------------------------- |
| `CLK`           | основной тактовый сигнал              |
| `RSTn`          | асинхронный сброс                     |
| `AD_DigData_In` | последовательные данные АЦП           |
| `AD_EOC`        | сигнал End-Of-Conversion (опционален) |

### **Выходы**

| Сигнал                           | Описание                  |
| -------------------------------- | ------------------------- |
| `AD_CSn`, `AD_Clk`, `AD_Address` | управление ADC            |
| `Data_Out[9:0]`                  | оцифрованные данные       |
| `CS_Valid_Sig`                   | момент валидности данных  |
| `Digitron_Out`                   | сегменты индикатора       |
| `DigitronCS_Out`                 | выбор разрядов индикатора |

# **8. Сборка в Quartus**

1. Создайте новый проект.
2. Добавьте файлы `AD.v`, `AD_Data.v`, `Digitron_NumDisplay.v`.
3. Добавьте `pll_100K` (IP-Core).
4. Установите верхний модуль:

   ```
   AD
   ```
5. Выполните Assignment → Pin Planner → назначьте выводы:

   * AD_CSn
   * AD_Clk
   * AD_Address
   * Digitron_Out
   * DigitronCS_Out

---

# **9. Результат**

После загрузки проекта на плату:

* АЦП начинает выборки с частотой ≈ **36.07 кГц**.
* 10-битные значения непрерывно отображаются на 7-сегментных индикаторах.
* Тайминги полностью соответствуют расчёту и данным SignalTap.
