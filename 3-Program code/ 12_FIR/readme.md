

# 🧪 Эксперимент: FIR-фильтр на FPGA (Cyclone IV)

### MINI_FPGA_CYCLONE4 — DDS → FIR → DAC

---

## 📌 1. Цель эксперимента

В данном эксперименте мы:

* генерируем две синусоидальные цифровые формы сигналов (6 кГц и 24 кГц) с помощью DDS;
* суммируем их, получая составной сигнал с двумя частотными компонентами;
* пропускаем сумму через **низкочастотный FIR-фильтр**, реализованный на базе IP-ядра Quartus;
* наблюдаем, как фильтр подавляет высокочастотную составляющую (24 кГц), пропуская низкочастотную (6 кГц);
* выводим цифровой результат на ЦАП платы MINI_FPGA_CYCLONE4 и исследуем аналоговый сигнал на осциллографе.

---

## 📌 2. Структура проекта

Проект состоит из следующих модулей:

### **1) `dds_module` — генератор двух синусоид**

* Фазовый DDS-накопитель для 6 кГц
* Фазовый DDS-накопитель для 24 кГц
* ПЗУ `sin6k_rom` и `sin24k_rom` со значениями синуса
* Разрядность выходов: **7 бит**

### **2) `pll_70K` — генератор частоты дискретизации**

* Системный такт (например, 50 МГц) преобразуется в **≈70 кГц**
* Эта частота подаётся на FIR-фильтр

### **3) `low_pass_filter1` — FIR низкочастотный фильтр**

* Сгенерирован в Qsys (Platform Designer)
* Интерфейс: Avalon-ST (sink/source)
* Разрядность выхода: **23 бита**
* Настройка: пропустить 6 кГц и подавить 24 кГц

### **4) `DA_Data_Out_module` — вывод на ЦАП**

* Формирует выход `DA_Data[7:0]`
* Передаёт тактовую частоту в ЦАП: `DA_CLK = CLK`
* Обеспечивает регистровую задержку данных

### **5) `fir_top` — верхний модуль**

Соединяет все блоки:

```
DDS → SUM → FIR → truncate → DAC → осциллограф
```

---

## 📌 3. Принцип работы

### ➤ 1. DDS формирует два дискретных синуса:

* 6 кГц: таблица глубиной 8192 слова
* 24 кГц: таблица глубиной 2048 слов

Адресы ПЗУ увеличиваются на каждом такте CLK, формируя равномерный дискретный синус.

### ➤ 2. Сигналы суммируются:

```
data_in = Sin6K_Out + Sin24K_Out    // 8 бит
```

### ➤ 3. FIR-фильтр обрабатывает сигнал

Параметры фильтра задаются в IP-ядре:

* Тип: **low-pass**
* Частота дискретизации: ≈70 кГц
* Полоса пропускания: пропускает 6 кГц
* Полоса подавления: значительно ослабляет 24 кГц

Выход FIR имеет **23 бита**, поэтому данные масштабируются.

### ➤ 4. На вход ЦАП подаются верхние 8 бит FIR-выхода:

```
DA_Data_In = data_out[22:15]
```

Это эквивалентно уменьшению амплитуды → важно учитывать при наблюдении на осциллографе.

### ➤ 5. Аналоговый сигнал наблюдается на осциллографе

На выходе ЦАП видим:

* при выключенном FIR → сумму двух синусоид
* при включённом FIR → почти чистый 6 кГц

---

## 📌 4. Тестовые режимы

Верхний модуль поддерживает несколько вариантов для отладки:

```verilog
/* assign DA_Data_In = {1'b0, Sin6K_Out}; */   // только 6 кГц
/* assign DA_Data_In = {1'b0, Sin24K_Out}; */  // только 24 кГц
/* assign DA_Data_In = data_in; */             // обе частоты, без фильтра

assign DA_Data_In = data_out[22:15];           // результат фильтрации
```

---

## 📌 5. Подключение оборудования

### Осциллограф

* Канал 1 → выход ЦАП (DA_Data)
* Общий → GND FPGA
* Режим: DC
* Масштаб: 1–2 В/дел

---

## 📌 6. Что нужно увидеть

### 🔹 До фильтрации (data_in):

На спектре два пика:

* **6 кГц**
* **24 кГц**

На временной осциллограмме — сложный немонохроматический сигнал.

---

### 🔹 После FIR-фильтра:

Ожидается:

* Высокочастотная составляющая (24 кГц) почти исчезает
* Сигнал становится плавным и похожим на чистый синус 6 кГц
* Амплитуда может уменьшиться из-за масштабирования разрядности
