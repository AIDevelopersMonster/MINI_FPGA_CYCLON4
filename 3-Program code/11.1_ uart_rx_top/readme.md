
# **UART RX на MINI_FPGA Cyclone IV**

Приём UART-данных с ПК и отображение принятого байта на светодиодах LED0–LED7

---

## 📌 **Описание проекта**

Этот проект реализует **UART-приёмник** на базе FPGA **Cyclone IV** (плата MINI_FPGA).
FPGA принимает данные по UART (скорость **9600 бод**), декодирует их и отображает принятый байт на **8 светодиодах**.

Архитектура состоит из четырёх модулей:

1. **detect_module** — детектор старт-бита (обнаружение фронта RX 1→0)
2. **rx_bps_module** — генератор тактов выборки UART (BPS clock)
3. **rx_control_module** — основной FSM-приёмник UART
4. **LED_display_module** — вывод принятого байта на светодиоды

Верхний модуль `rx_top.v` объединяет всю логику.

## 📝 **Принцип работы UART-приёмника**

### 1️⃣ Обнаружение старт-бита

Линия UART находится в состоянии «1».
Когда ПК отправляет байт — появляется переход **1 → 0**.
`detect_module` формирует короткий импульс `neg_sig`.

---

### 2️⃣ Запуск генератора скорости (BPS)

`rx_bps_module` начинает отсчёт длительности одного UART-бита:

```
50_000_000 Гц / 9600 = 5208 тактов
```

На середине каждого интервала выдаётся `BPS_CLK` — идеальный момент для считывания данных.

---

### 3️⃣ FSM приёма (rx_control_module)

Автомат последовательно:

* ждёт середину старт-бита
* считывает **8 бит данных**
* проверяет четность и сравнивает с полученным битом четности
* проверяет стоп-бит
* выставляет `RX_Done_Sig`
* передаёт принятый байт в `RX_Data`

---

### 4️⃣ Отображение результата

`LED_display_module` обновляет LED0–LED7 при приходе `RX_Done_Sig`.

Таким образом, каждый принятый символ отображается на LED в виде его ASCII-кода.

## 🖼 **Диаграмма кадра UART (9600 бод)**

```
Idle  Start  D0  D1  D2  D3  D4  D5  D6  D7  Stop
  1     0     b0  b1  b2  b3  b4  b5  b6  b7   1
```

## ▶️ **Как протестировать**

1. Скомпилировать проект в Quartus
2. Прошить FPGA
3. Подключить USB-UART адаптер
4. Настроить терминал (Putty, CoolTerm, RealTerm):

   * **9600 бод**
   * 8 бит
   * бит четности
   * 1 стоп-бит
5. Отправлять ASCII-символы
6. Светодиоды покажут принятый байт

Например:
Отправим `'A'` (0x41) → LED отобразят:

```
0100 0001
```
