# **UART TX — MINI_FPGA Cyclone IV**

Проект демонстрирует реализацию передатчика UART (TX) на FPGA Cyclone IV с использованием трёх модулей:
**управление данными → генератор бод-частоты → побитный передатчик**.

Передача идёт со скоростью **9600 бод**, формат кадра — **1 старт-бит + 8 данных + 1 стоп-бит**.

Все модули написаны на Verilog и легко адаптируются для любых скоростей и форматов UART.

---

## **1. Структура проекта**

Проект состоит из следующих модулей:

```
tx_top.v               – верхний модуль, соединяющий все блоки
data_control_module.v  – формирование данных и сигнала TX_En_Sig
tx_bps_module.v        – генератор BPS_CLK (частоты UART)
tx_control_module.v    – побитный передатчик UART
```

---

## **2. Принцип работы UART TX**

UART передаёт кадр последовательно:

```
Старт-бит (0)
Бит 0
Бит 1
...
Бит 7
Стоп-бит (1)
```

Линия TX в состоянии покоя = **1**.

Посылка данных идёт **LSB first**.

## **4. Описание модулей**

### **4.1 data_control_module**

* Формирует последовательность байтов:
  **0x0A, 0x0B, 0x0C, 0x0D, 0x0E, 0x0F**
* Каждые 0.5 секунды запускает передачу.
* Генерирует сигнал **TX_En_Sig**, который разрешает отправку кадра.

---

### **4.2 tx_bps_module**

Генерирует сигнал **BPS_CLK**, который является "меткой" середины каждого битового интервала.

Для частоты 50 МГц и скорости 9600 бод:

```
BPS_T = 50_000_000 / 9600 ≈ 5208
Середина битового интервала = 2604
```

При достижении половины периода одиночный импульс → **BPS_CLK = 1**.

---

### **4.3 tx_control_module**

Формирует UART-кадр:

1. Старт-бит = 0
2. Передаёт 8 бит TX_Data
3. Стоп-бит = 1
4. Выдаёт сигнал **TX_Done_Sig**

Вся логика работает по импульсам **BPS_CLK**, что гарантирует устойчивую скорость передачи.

---

### **4.4 tx_top**

Соединяет модули:

```
data_control → tx_bps → tx_control
```

Вывод **TX_Pin_Out** подключается к:

* USB-UART адаптеру,
* COM-порту,
* логическому анализатору.

---

## **5. Подключение TX_Pin_Out**

Если используется USB-UART CH340/FT232:

```
FPGA   →   USB-UART
TX     →   RX
GND    →   GND
```

**Важно:** скорость порта в терминале = **9600 8N1**.

---

## **6. Настройки проекта**

### **Частота FPGA**

Проект рассчитан на **CLK = 50 MHz**.

### **UART скорость**

9600 бод, но можно изменить, заменив:

```
parameter BPS_T = CLOCK_FREQ / BAUD_RATE;
```

---

## **7. Вывод в терминале**

При корректном подключении каждые 0.5 секунды выводятся символы:

```
0x0A
0x0B
0x0C
0x0D
0x0E
0x0F
```

Терминал может отображать их как пустые строки, если символы не печатные — это нормально.
При необходимости можно заменить данные на ASCII, например `'A','B','C'`.

---

## **8. Пин-план (пример)**

Для FPGA Cyclone IV EP4CE6:

| Назначение | Пин    | Направление |
| ---------- | ------ | ----------- |
| CLK        | PIN_23 | input       |
| RSTn       | SW0    | input       |
| TX         | F14    | output      |
