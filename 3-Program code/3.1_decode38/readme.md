# 3.1 — Декодер 3→8 (3-to-8 Decoder)

Этот проект демонстрирует работу классического цифрового устройства — **декодера 3→8**, который преобразует трёхбитовый двоичный код на входе в восемь взаимно-исключающих сигналов на выходе.
Используется плата **MINI_FPGA на базе Cyclone IV EP4CE6**.

---

## 📌 Структура проекта

В проект входят два модуля:

### **1. Верхний уровень — `decode38.v`**

Подключает переключатели `SW_In[2:0]` к входам декодера и отображает результат на светодиодах `LED_Out[7:0]`.

### **2. Логический модуль — `decode_module.v`**

Реализует саму логику декодера 3→8 вида:

```
a2 a1 a0  →  y7..y0 (активен только один)
```

## ⚙️ Логика работы

Декодер включает **только один LED**, соответствующий двоичному коду на входах `a2 a1 a0`.

| Вход (`SW_In`) | Активный выход (LED) |
| -------------- | -------------------- |
| 000            | y0 → LED0            |
| 001            | y1 → LED1            |
| 010            | y2 → LED2            |
| 011            | y3 → LED3            |
| 100            | y4 → LED4            |
| 101            | y5 → LED5            |
| 110            | y6 → LED6            |
| 111            | y7 → LED7            |

## 🧩 Код модулей

### **decode_module.v**

```verilog
module decode_module
(
    a2, a1, a0,
    y7, y6, y5, y4, y3, y2, y1, y0
);

    input  wire a2, a1, a0;
    output wire y7, y6, y5, y4, y3, y2, y1, y0;

    assign y0 = ~a2 & ~a1 & ~a0;
    assign y1 = ~a2 & ~a1 &  a0;
    assign y2 = ~a2 &  a1 & ~a0;
    assign y3 = ~a2 &  a1 &  a0;
    assign y4 =  a2 & ~a1 & ~a0;
    assign y5 =  a2 & ~a1 &  a0;
    assign y6 =  a2 &  a1 & ~a0;
    assign y7 =  a2 &  a1 &  a0;

endmodule
```

---

### **decode38.v**

```verilog
module decode38
(
    Sw_In, 
    LED_Out
);

    input  wire [2:0] Sw_In;
    output wire [7:0] LED_Out;

    decode_module U1
    (
        .a2( Sw_In[2] ),
        .a1( Sw_In[1] ),
        .a0( Sw_In[0] ),

        .y7( LED_Out[7] ),
        .y6( LED_Out[6] ),
        .y5( LED_Out[5] ),
        .y4( LED_Out[4] ),
        .y3( LED_Out[3] ),
        .y2( LED_Out[2] ),
        .y1( LED_Out[1] ),
        .y0( LED_Out[0] )
    );

endmodule
```

## 🔌 Pin Planner (рекомендуемая распиновка)

| Сигнал       | Плата | Назначение  |

| `SW_In[0]`   | SW0   | младший бит |

## 🧪 Как протестировать

1. Загрузите проект в Quartus.
2. Назначьте выводы в Pin Planner.
3. Скомпилируйте проект.
4. Залейте `.sof` на FPGA.
5. Переключайте `SW2–SW0` — будет светиться только один LED.
