
# 📘 mux81 — Мультиплексор 8 к 1 (MINI_FPGA Cyclone IV)

Данный проект реализует параметризуемый мультиплексор **8 → 1** для обучения работе с базовыми цифровыми схемами на FPGA **Cyclone IV**.
Модуль поддерживает произвольную разрядность данных (параметр `width`) и входной сигнал разрешения `CSn` (активный низкий).

Используется в учебном проекте **MINI_FPGA_CYCLON4**.

---

## 📌 Назначение мультиплексора 8→1

**Мультиплексор (MUX)** — это цифровое устройство, которое позволяет выбрать один из нескольких входов и направить его на общий выход.

В нашем случае:

* 8 входных каналов: **D0 ... D7**
* 1 трёхбитный селектор: **A[2:0]**
* 1 выход: **Y**
* Сигнал разрешения: **CSn**

  * `CSn = 0` → мультиплексор работает
  * `CSn = 1` → выход принудительно сброшен в 0

Мультиплексоры применяются в:

* коммутации сигналов
* выборке данных
* формировании шин
* системах управления
* ALU и datapath
* построении ROM/таблиц поиска

# 🔧 Код модуля mux81_module

```verilog
//=======================================================
// 8:1 Multiplexer Core (mux81_module)
// Плата: MINI_FPGA (Cyclone IV)
//=======================================================

module mux81_module
(
	CSn, A, D0, D1, D2, D3, D4, D5, D6, D7, Y
);

	 input CSn;                   
	 input [2:0]A;               
	 input [width-1:0]D0, D1, D2, D3, D4, D5, D6, D7;	 
	 output reg [width-1:0]Y;

	 parameter width = 1;

	always @(*) begin 
		if (!CSn)									//While CSn = 0, mux81 works
			case (A)
				3'b000: Y <= D0;
				3'b001: Y <= D1;
				3'b010: Y <= D2;
				3'b011: Y <= D3;
				3'b100: Y <= D4;
				3'b101: Y <= D5;
				3'b110: Y <= D6;
				3'b111: Y <= D7;
			endcase
		else
			Y <= 0;									//While CSn = 1, output reset
	end

endmodule
```

## 🧩 Верхний модуль (top)

```verilog
module mux81
(
	CSn, Sw_In,
	Key_In0, Key_In1, Key_In2, Key_In3,
	Key_In4, Key_In5, Key_In6, Key_In7,
	LED_Out
);
	 input CSn;
	 input [2:0]Sw_In;
	 input [width-1:0]Key_In0, Key_In1, Key_In2, Key_In3;
	 input [width-1:0]Key_In4, Key_In5, Key_In6, Key_In7;
	 output [width-1:0]LED_Out;

	 parameter width = 1;

	mux81_module #(.width(width)) U1
	(
		.CSn( CSn ),
		.A( Sw_In ),
		.D0( Key_In0 ), .D1( Key_In1 ), .D2( Key_In2 ), .D3( Key_In3 ),
		.D4( Key_In4 ), .D5( Key_In5 ), .D6( Key_In6 ), .D7( Key_In7 ),
		.Y( LED_Out )
	);

endmodule
```

# 📘 Теория: почему мультиплексор — важный элемент цифровой логики?

Мультиплексор  — это **цифровой коммутатор**, который позволяет выбирать один сигнал из нескольких.
Он лежит в основе:

### ✔ ALU

Выбор между операциями (сложение, вычитание, AND, OR, XOR):

### ✔ Datapath

Выбор источника данных для следующего регистра.

### ✔ Memory I/O

Выбор между ROM/ RAM/ регистром.

### ✔ Таблицы истинности и ROM

MUX с 8 входами = ROM на 3 адресных линии.

### ✔ Многоразрядных шин

Благодаря параметру `width` можно легко создать:

* 8→1 для шины 4 бит
* 8→1 для шины 8 бит
* 8→1 для шины 16 бит

---

# 🧪 Работа на плате MINI_FPGA (Cyclone IV)

* `Sw_In[2:0]` → выбор канала
* `Key_In0..Key_In7` → источники данных
* `LED_Out` показывает выбранный источник
* `CSn` позволяет:

  * включить мультиплексор
  * или принудительно обнулить выход

---

# ▶ Как использовать

1. Создать проект в Quartus
2. Добавить файлы `mux81.v` и `mux81_module.v`
3. Назначить пины на MINI_FPGA:

   * переключатели → `Sw_In`
   * кнопки или GPIO → `Key_In0..7`
   * светодиоды → `LED_Out`
4. Скомпилировать и прошить плату

---

# 📷 Демонстрация

* Переключая `Sw_In`, вы выбираете один из входных каналов.
* Смена `Key_InX` сразу отображается на `LED_Out`.
