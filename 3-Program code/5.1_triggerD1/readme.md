
# 📘 **5.1 TriggerD1 (Асинхронный D-триггер)**

## 📌 Описание проекта

В этом задании реализуется однобитный **D-триггер с асинхронными входами Setn и Clrn**, собранный на базе внутреннего модуля `trigger_module`.
Верхний уровень `triggerD1` только подключает сигналы платы MINI_FPGA (Cyclone IV) к этому модулю.

---

## 🔧 **Структура проекта**

```
triggerD1.v      – верхний уровень
trigger_module.v – сам D-триггер
```

---

## ⚙️ **Параметры и сигналы**

### Входы:

| Сигнал  | Описание                           |
| ------- | ---------------------------------- |
| `CLK`   | тактовый сигнал                    |
| `Setn`  | асинхронная установка (активный 0) |
| `Clrn`  | асинхронный сброс (активный 0)     |
| `Sw_In` | вход D-триггера                    |

### Выходы:

| Сигнал    | Описание           |
| --------- | ------------------ |
| `LED_Out` | состояние выхода Q |

---

# 🧠 **Теория: как работает D-триггер**

D-триггер — это базовый элемент цифровой логики, который запоминает 1 бит информации.
Его ключевые свойства:

### ✔ Тактирование по фронту (`posedge CLK`)

При каждом положительном фронте триггер делает:

```
Q <= D
```

### ✔ Асинхронный Setn и Clrn

Они **всегда работают**, независимо от CLK.

| Setn | Clrn | Результат                                      |
| ---- | ---- | ---------------------------------------------- |
| 0    | 1    | Q = 1 (установка)                              |
| 1    | 0    | Q = 0 (сброс)                                  |
| 0    | 0    | запрещено (в реальных ПЛИС — неопределённость) |
| 1    | 1    | триггер работает нормально                     |

Приоритет обычно такой:

```
1) Сначала Clrn (сброс)
2) Потом Setn (установка)
3) Только потом D по CLK
```

---

## ❗ Почему выход **Q** имеет приоритет Setn > Clrn?

Это связано с тем, как компилирует Quartus и как построены физические "primitive"-ячейки в Cyclone IV.

В реальном LE (Logic Element) FPGA:

```
Async Clear имеет приоритет над Async Set
```

Но чаще в учебных примерах ставят Setn выше — чтобы показать поведение вручную.

Итог: **Setn/Clrn всегда важнее D и CLK**.

---

# 📦 **Код верхнего уровня**

```verilog
module triggerD1
(
	CLK, Setn, Clrn, Sw_In, LED_Out
);
	
    input CLK;
	input Setn;
	input Clrn;
	input Sw_In;
	output LED_Out;

	trigger_module U1
	(
		.CLK( CLK ),	
		.Setn( Setn ),	
		.Clrn( Clrn ),	
		.D( Sw_In ),	
		.Q( LED_Out ) 	
	);	
	
endmodule
```
