
# 🟦 MINI_FPGA_CYCLON4 — 8-битный D-триггер

## Файл: **triggerD2** + **trigger_module**

Этот проект демонстрирует работу **8-битного D-триггера** с асинхронными входами установки (**Setn**) и сброса (**Clrn**). Реализация выполнена **поведенческим описанием** на Verilog, как это принято в цифровой логике и FPGA-разработке.

---

## 📘 Назначение работы

* Изучить принцип работы D-триггера.
* Научиться использовать **асинхронные входы** Setn и Clrn.
* Выполнить реализацию **8-битного регистра**, который сохраняет данные на фронте тактового сигнала.
* Отобразить состояние триггера на светодиодах FPGA-платы MINI_FPGA (Cyclone IV).

---

## 🧩 Структура проекта

Проект состоит из двух файлов:

### ✔ **1. triggerD2.v**

Верхний модуль, который:

* принимает сигналы `CLK`, `Setn`, `Clrn`
* принимает 8-битное значение `Sw_In`
* выводит 8-битный результат `LED_Out`
* содержит инстанс модуля `trigger_module`

### ✔ **2. trigger_module.v**

Логика 8-битного D-триггера с асинхронными входами, выполненная **поведенческим описанием**:

* `Setn = 0` → все биты Q принудительно устанавливаются в 1
* `Clrn = 0` → все биты Q принудительно сбрасываются в 0
* `posedge CLK` → Q принимает значение D

---

## ⚙ Принцип работы D-триггера

D-триггер — это базовая ячейка памяти, которая:

### ➤ Хранит 1 бит информации

(в нашем случае — сразу 8 бит)

### ➤ Обновляет своё состояние только в момент фронта CLK

То есть входные данные **D** копируются в **Q** только при переходе тактового сигнала:

```
CLK:  ____/‾‾‾\____/‾‾‾\____
             ^
             | здесь Q <= D
```

### ➤ Асинхронно реагирует на входы Setn и Clrn

Эти сигналы **не зависят от такта**:

* `Setn = 0` → Q устанавливается в `1111_1111`
* `Clrn = 0` → Q сбрасывается в `0000_0000`

Асинхронные входы всегда имеют **приоритет над тактовым входом**.

---

## 📄 Ключевые фрагменты кода

### Поведенческое описание (always + if/else):

```verilog
always @(posedge CLK or negedge Setn or negedge Clrn)
begin
    if (!Setn)
        Q <= 8'hFF;        // Асинхронная установка
    else if (!Clrn)
        Q <= 8'h00;        // Асинхронный сброс
    else
        Q <= D;            // Захват данных по фронту такта
end
```

Это — классический грамотный D-триггер.

---

## 🧪 Практическое применение на FPGA MINI_FPGA (Cyclone IV)

Вы можете:

* Подключить переключатели SW0–SW7 к входам `D`
* Подать фронты CLK (например, от генератора или делителя частоты)
* Нажатием Setn принудительно установить выходы LED0–LED7
* Нажатием Clrn — асинхронно сбросить их

Таким образом, плата работает как **8-битный регистр с управлением**.
