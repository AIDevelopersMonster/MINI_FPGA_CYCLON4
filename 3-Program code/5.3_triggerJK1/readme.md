🟦 MINI_FPGA (Cyclone IV) — JK Trigger Module
4-bit JK-триггер с делителем частоты
Файлы: triggerJK1.v, trigger_module.v
📌 Описание проекта

В данном упражнении реализуется четырёхразрядный JK-триггер, управляемый асинхронными входами Setn и Clrn, со сниженной частотой тактирования для наглядной индикации на светодиодах.

Топ-модуль triggerJK1 получает 8 входных переключателей:

J[7:4] → J[3:0],

K[3:0] → K[3:0],

и передаёт их во внутренний модуль trigger_module, который реализует:

4 независимых JK-триггера,

генерацию инверсных выходов Q_n,

встроенный делитель частоты (медленный CLK1),

асинхронные входы Setn/Clrn (active low).

🧠 Теория: как работает JK-триггер

Для каждого бита:

J	K	Состояние Q_next
0	0	сохраняет Q
0	1	сбрасывает (0)
1	0	устанавливает (1)
1	1	переключает (toggle)

Формула:

Q_next = (J & ~Q) | (~K & Q)


В коде используется Q_n вместо ~Q, но логика полностью эквивалентна.

Асинхронные входы:

Setn = 0 → Q = 1

Clrn = 0 → Q = 0

Имеют приоритет над J/K-логикой.

⏱ Встроенный делитель частоты (CLK → CLK1)

Часто реальный тактовый генератор слишком быстрый для визуального наблюдения на светодиодах.
Поэтому используется счётчик:

Count == Timex - 1 → переключение CLK1


Пример:

Timex = 200_000 → около 250 Гц при входном 50 МГц


Что удобно для наблюдения функций триггера.

🧩 Верхний модуль (triggerJK1)

Принимает 8 переключателей:

Sw_In[7:4] → J

Sw_In[3:0] → K

Отображает:

Q → LED_Out[7:4]

Q_n → LED_Out[3:0]

⚙ Внутренний модуль (trigger_module)

Реализует:

Логику JK-триггера,

Генерацию инверсного выхода Q_n,

Делитель частоты,

Асинхронные Setn/Clrn.

🔌 Подключение пинов в Quartus

Примерная схема:

Сигнал	Назначение
CLK	тактовый вход платы
Setn	кнопка установки (active low)
Clrn	кнопка сброса (active low)
Sw_In[7:0]	8 переключателей
LED_Out[7:0]	8 светодиодов
🧪 Как проверить работу

Установите Setn=1, Clrn=1.

Подайте комбинации J/K на любой канал:

J=1, K=0 → LED = 1

J=0, K=1 → LED = 0

J=1, K=1 → LED мигает (toggle)

Нажмите Clrn → все Q = 0.

Нажмите Setn → все Q = 1.

Наблюдайте медленные переключения благодаря делителю частоты.
