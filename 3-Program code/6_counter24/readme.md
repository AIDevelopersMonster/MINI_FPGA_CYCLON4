# ✅ **README.md — Эксперимент: 24-ричный счётчик с выводом на 7-сегментный индикатор**

# MINI_FPGA (Cyclone IV)

## Эксперимент: 24-ричный счётчик + динамическая индикация (7-сегментный индикатор)

Этот эксперимент демонстрирует, как на FPGA Cyclone IV реализовать:

* делитель частоты → формирование секундного такта;
* BCD-счётчик по модулю 24 (0..23);
* динамическую индикацию двух цифр на 7-сегментных индикаторах;
* верхний модуль, объединяющий всю логику.

Эксперимент состоит из трёх модулей:

| Модуль                         | Назначение                                              |
| ------------------------------ | ------------------------------------------------------- |
| **Accumulator_module**         | Делитель частоты + BCD-счётчик 0..23                    |
| **Digitron_NumDisplay_module** | Драйвер динамической индикации (7-сегментный индикатор) |
| **counter24**                  | Верхний модуль, соединяющий оба блока                   |

---

## 🔧 **1. Accumulator_module — счётчик 0..23**

### Функции:

* Делит частоту системного генератора (50 МГц → ~1 Гц).
* Под каждым фронтом `CLK1` увеличивает BCD-счётчик.
* Диапазон: **00 → 23 → 00**.
* Результат выдаёт в формате двух цифр BCD:

  * `Result[3:0]` — младшая цифра (единицы),
  * `Result[7:4]` — старшая цифра (десятки).

### Использование:

Этот модуль — «сердце» всей системы. Он производит число для отображения.

---

## 🔦 **2. Digitron_NumDisplay_module — динамическая индикация**

Модуль преобразует `Result[7:0]` в сегменты для 7-сегментных индикаторов.

### Функции:

* Поочерёдно активирует разряды через `DigitronCS_Out`.
* Преобразует BCD-цифры в сегменты (`Digitron_Out`).
* Работает по принципу **динамического сканирования** — очень быстро переключает разряды, имитируя "одновременное" свечение.

### Используются только два разряда:

* единицы,
* десятки.

Остальные отключены, но структура позволяет расширение до 6 разрядов.

---

## ⛓️ **3. counter24 — верхний модуль**

Соединяет оба функциональных блока:

```
           +----------------------+
 CLK ----> | Accumulator_module   | ----> Result[7:0]
 RSTn ---->| (счётчик 0..23)      |
           +----------------------+
                        |
                        v
           +------------------------------+
           | Digitron_NumDisplay_module   |
           | (динамическая индикация)     |
           +------------------------------+
                 |                  |
         Digitron_Out[7:0]   DigitronCS_Out[5:0]
```

### Выводы:

* `Digitron_Out` → сегменты индикаторов
* `DigitronCS_Out` → выбор разряда
* `RSTn` → SW0
* `CLK` → системный генератор платы

# 🧪 Как запустить

1. Добавь в Quartus три файла:

   * `Accumulator_module.v`
   * `Digitron_NumDisplay_module.v`
   * `counter24.v`
2. Настрой пины под свою плату MINI_FPGA (Cyclone IV):

   * Digitron Out A..DP
   * CS0..CS5
   * CLK 50 MHz
   * SW0 → RSTn
3. Скомпилируй и прошей FPGA.
4. На индикаторе начнёт отображаться значение, увеличивающееся каждую секунду:
   **00, 01, 02… 23 → 00 → ...**
