# 7. Responder — система быстрого ответа на FPGA (Cyclone IV)

В этом эксперименте реализована полноценная система быстрого ответа (**Responder**) для 4 игроков на учебной плате **MINI_FPGA_CYCLON4** с FPGA **Cyclone IV**.
Проект демонстрирует работу нескольких цифровых блоков:

* логика выбора первого игрока;
* таймер обратного отсчёта;
* генерация разных тонов на буззер;
* динамическая индикация на семисегментных индикаторах;
* объединение всех модулей в единый top-level.

Проект можно легко расширять под учебные задачи, викторины, соревнования или лабораторные работы.

---

## 📌 Основной функционал Responder’а

* 4 игрока → кто нажал первым — тот «победил».
* Остальные игроки блокируются до нового раунда.
* Ведущий может запустить раунд кнопкой `Start`.
* Автоматический таймер обратного отсчёта (30 секунд).
* Звуковая индикация:

  * короткий сигнал при успешном ответе,
  * длинный/иной тон в момент окончания времени.
* Номер игрока + оставшееся время отображаются на 7-seg индикаторе.
* Отдельный светодиод `LED_OverTime` показывает «время вышло».

---

## 📡 Структура проекта и модули

Проект состоит из 5 основных модулей:

```
responder (top)
 ├── Sel_module              — выбор первого игрока
 ├── Timer_module            — таймер обратного отсчёта
 ├── Buzzer_module           — генератор звуковых сигналов
 └── Digitron_NumDisplay_module — мультиплексная индикация
```

### 1. responder (top-level)

Главный модуль соединяет все остальные:

* принимает сигналы кнопок игроков;
* запускает таймер;
* передаёт номер игрока на индикацию;
* включает буззер при нужных событиях.

**Порты верхнего уровня:**

| Порт                | Направление | Описание                           |
| ------------------- | ----------- | ---------------------------------- |
| RSTn                | input       | глобальный сброс (SW0, активный 0) |
| Start               | input       | запуск нового раунда (SW1)         |
| Key_In[3:0]         | input       | кнопки игроков                     |
| LED_Out[3:0]        | output      | кто нажал первым                   |
| LED_OverTime        | output      | время вышло                        |
| Buzzer_Out          | output      | выход на буззер                    |
| Digitron_Out[7:0]   | output      | сегменты                           |
| DigitronCS_Out[5:0] | output      | выбор разрядов                     |

---

### 2. Sel_module — логика выбора игрока

Главный смысл модуля:

* принимает события от кнопок `K1..K4`,
* определяет, кто нажал **первым**,
* фиксирует победителя (флаг `Block`),
* подаёт:

  * импульс `Buzzer_Answer`,
  * сигнал `Timer_Start`,
* выводит номер игрока в `Player_Number`,
* зажигает один из LED’ов.

Алгоритм:

1. Нажатие первой доступной кнопки → игрок определяется.
2. Остальные нажатия игнорируются.
3. Запускается таймер.
4. На буззер подаётся короткий сигнал (импульс).

---

### 3. Timer_module — таймер обратного отсчёта

Функции:

* делит частоту `CLK` до примерно 1 Гц;
* обратный отсчёт: 30 → 29 → … → 01 → 00;
* при `00:01` выдаёт:

  * `Buzzer_TimeOver`,
  * `LED_OverTime`.

Используются два разряда: `TimerH` и `TimerL`.

Работает только при `Timer_Start = 1`.

---

### 4. Buzzer_module — генератор звуковых сигналов

Генерирует **два разных тона**:

| Событие      | Вход            | Частота   |
| ------------ | --------------- | --------- |
| Ответ принят | Buzzer_Answer   | _Answer   |
| Время вышло  | Buzzer_TimeOver | _TimeOver |

Частота формируется через делитель счётчика:

```verilog
parameter _Answer = 17'd95419;
parameter _TimeOver = 17'd50607;
```

Получается:

* «писк» при ответе,
* «длинный сигнал» при окончании времени.

Если нет событий → буззер молчит.

---

### 5. Digitron_NumDisplay_module — динамический вывод на 7-seg

Показывает:

* `TimerL`
* `TimerH`
* `Player_Number`

Переключение разрядов ≈ каждые 200 тактов, что создаёт эффект одновременной индикации.

Имеет встроенную таблицу сегментов `_0 ... _9`.

Работает по принципу:

```
Разряд 1 → TimerL
Разряд 2 → TimerH
Разряд 3 → Player_Number
```

## ▶️ Как пользоваться системой

1. Установите `RSTn = 0`, затем верните в `1` → сброс.
2. Переведите `Start = 1` → раунд открыт.
3. Игроки нажимают свои кнопки:

   * первый победил,
   * остальные игнорируются.
4. Таймер начинает отсчёт с 30 секунд.
5. Если игрок успел → буззер подаёт короткий «пик».
6. Если время вышло:

   * загорается индикатор `LED_OverTime`,
   * звучит другой тон буззера.
7. Для нового раунда нажмите `Start` ещё раз или сбросьте систему.
