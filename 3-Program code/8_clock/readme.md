
# **Digitron_TimeDisplay_module — Модуль отображения времени и дня недели на 7-сегментном индикаторе**

## **Описание**

`Digitron_TimeDisplay_module` — это модуль для управления 6-разрядным семисегментным индикатором (DIGITRON) на плате **MINI_FPGA Cyclone IV**.
Модуль выполняет динамическое мультиплексирование (сканирование) разрядов и обеспечивает два режима отображения:

### **1. Отображение времени (HH:MM:SS)**

В нормальном режиме модуль выводит текущее время:

* **HourH, HourL** — часы
* **MinH, MinL** — минуты
* **SecH, SecL** — секунды

Мультиплексирование выполняется с частотой, исключающей мерцание.

### **2. Отображение дня недели**

При активных сигналах:

* `DispWeek_n = 0`
* или `AdjtWeek = 1`

на индикатор выводится только значение `Week` (1…7).

День недели отображается на крайнем правом разряде, остальные гаснут.

---

## **Назначение входов и выходов**

| Сигнал                | Направление | Описание                   |
| --------------------- | ----------- | -------------------------- |
| `CLK`                 | input       | системный такт (50 МГц)    |
| `RSTn`                | input       | сброс (активный 0)         |
| `DispWeek_n`          | input       | отображать день недели     |
| `AdjtWeek`            | input       | режим настройки недели     |
| `SecL, SecH`          | input       | секунды (BCD)              |
| `MinL, MinH`          | input       | минуты (BCD)               |
| `HourL, HourH`        | input       | часы (BCD)                 |
| `Week`                | input       | день недели (1…7)          |
| `Digitron_Out[7:0]`   | output      | сегменты a–g, dp           |
| `DigitronCS_Out[5:0]` | output      | выбор разряда (активный 0) |

---

## **Принцип работы**

### **Мультиплексирование разрядов**

Модуль включает один из 6 разрядов, последовательно сканируя их:

```
HourH → HourL → MinH → MinL → SecH → SecL
```

Каждый разряд удерживается активным `T100MS` тактов.

### **Таблица отображения цифр**

Коды сегментов заданы для цифр **0–9**, а также есть специальный вариант `_Ri` для Week=7.

### **Логика выбора режима**

```
if (DispWeek_n == 0 OR AdjtWeek == 1)
    отображаем Week
else
    отображаем HH:MM:SS
```

---

## **Особенности реализации**

* Отображение основано на динамическом мультиплексировании (быстрое переключение разрядов).
* День недели отображается только на одном разряде.
* Время отображается полностью: сек., мин., часы.
* Сегменты формируются по BCD-коду.
* Модуль не обрабатывает debounce кнопок (делается выше).

Модуль является частью системы часов:

```

```

## **Пример подключения**

```verilog
Digitron_TimeDisplay_module U2
(
    .CLK            ( CLK ),
    .RSTn           ( RSTn ),
    .DispWeek_n     ( DispWeek_n ),
    .AdjtWeek       ( AdjtWeek ),
    .Digitron_Out   ( Digitron_Out ),
    .DigitronCS_Out ( DigitronCS_Out ),
    .SecL           ( SecL ),
    .SecH           ( SecH ),
    .MinL           ( MinL ),
    .MinH           ( MinH ),
    .HourL          ( HourL ),
    .HourH          ( HourH ),
    .Week           ( Week )
);
```

## **Назначение в системе часов**

Модуль полностью отвечает за визуальную часть проекта:

* Отображение текущего времени
* Индикация режима настройки дня недели
* Отображение значения Week

Он напрямую получает данные от `TimeKeeper_module`.
