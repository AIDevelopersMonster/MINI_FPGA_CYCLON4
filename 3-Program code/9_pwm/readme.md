
# **PWM Generator — MINI_FPGA_CYCLON4**

Регулируемая скважность и частота PWM + вывод на LED и 7-segment

---

## 📘 **Описание эксперимента**

Этот эксперимент демонстрирует работу **широтно-импульсной модуляции (PWM)** на ПЛИС Cyclone IV:

* изменение **скважности (Duty)** шагом 10%;
* изменение **периода/частоты PWM** (1000 Гц → 200 Гц → 100 Гц);
* отображение текущих значений **Count_D / Count_P / Duty** на 6-разрядном семисегментном индикаторе;
* вывод PWM:

  * на **LED0** (яркость меняется),
  * на пин **A6 (EPI)** — для наблюдения в Pocket Instrument / осциллографе.

Модули полностью разделены по функциям:

* регулировка параметров,
* генерация PWM,
* отображение чисел,
* антидребезг кнопок.

---

## 📐 **Структура проекта**

```
pwm.v                        - верхний модуль
 |- Duty_Period_Adjust_module.v   - регулировка Duty и Period
 |- PWM_Generate_module.v         - генерация сигнала PWM
 |- Digitron_NumDisplay_module.v  - вывод на 7 сегментов
 |- Jitter_Elimination_module.v   - устранение дребезга кнопок
```

## 🎛 **Управление на плате**

### Кнопки (KEY)

| Кнопка   | Функция                              |
| -------- | ------------------------------------ |
| **KEY3** | Увеличить Duty                       |
| **KEY2** | Уменьшить Duty                       |
| **KEY1** | Увеличить Period (уменьшить частоту) |
| **KEY0** | Уменьшить Period (увеличить частоту) |

После каждого нажатия происходит единичное обновление (антидребезг встроен).

---

### Переключатели (SW)

| SW      | Назначение                 |
| ------- | -------------------------- |
| **SW0** | RSTn — сброс всего проекта |
| **SW1** | Показать Count_D           |
| **SW2** | Показать Count_P           |

Если SW1 и SW2 = 0 → выводится Duty.

---

## 💡 **Изменение частоты PWM**

Период PWM задаётся параметром **Count_P**
(частота FPGA = 50 МГц):

| Count_P | Период | Частота                        |
| ------- | ------ | ------------------------------ |
| 500 000 | 10 ms  | 100 Hz                         |
| 250 000 | 5 ms   | 200 Hz (значение по умолчанию) |
| 50 000  | 1 ms   | 1000 Hz                        |

---

## 🌈 **Изменение скважности (Duty)**

Duty хранится в диапазоне **0–100**.
Шаг изменения — **10**.

При достижении края — значение делает круг:

* 100 → 0
* 0 → 100

---

## 🔌 **Выходы**

| Выход                 | Назначение                                            |
| --------------------- | ----------------------------------------------------- |
| `PWM_LED_Out`         | вывод PWM на LED0                                     |
| `PWM_EPI_Out`         | вывод PWM на пин A6, подключаемый к Pocket Instrument |
| `Digitron_Out[7:0]`   | сегменты a-g + dp                                     |
| `DigitronCS_Out[5:0]` | выбор разрядов индикатора                             |

`PWM_EPI_Out` = `PWM_LED_Out`.

## 🧩 **Описание модулей**

### ### 1. `Duty_Period_Adjust_module`

* Обрабатывает кнопки (через модуль антидребезга).
* Регулирует Duty (0–100).
* Переключает Count_P между трёмя предустановками.

### 2. `PWM_Generate_module`

Вычисляет:

```
Count_D = (Duty * Count_P) / 100
```

Генерирует PWM:

```
Cn1 = from 0 to Count_P-1
PWM_Out = (Cn1 <= Count_D)
```

### 3. `Digitron_NumDisplay_module`

Показывает:

* 6 шестнадцатеричных цифр Count_P
* или 6 цифр Count_D
* или 2 цифры Duty

Мультиплексирование — кольцевой регистр катодов.

### 4. `Jitter_Elimination_module`

Простой двухтактный синхронизатор + детектор фронта 1→0.

---

## 🖥 **Наблюдение PWM на EPI / осциллографе**

Подключив пин A6 к инструменту EPI:

* видно изменение duty — ширина импульса увеличивается/уменьшается;
* видно изменение периода — сигнал растягивается/сжимается.

LED0 показывает усреднённую яркость, а EPI — реальную цифровую форму.
