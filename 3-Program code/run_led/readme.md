
# MINI_FPGA_CYCLON4 — Учебные примеры для Cyclone IV

Добро пожаловать в репозиторий учебного проекта **MINI_FPGA_CYCLON4**, созданного на базе FPGA-платы с чипом **Intel/Altera Cyclone IV (EP4CE6/EP4CE10)**.  
Проект служит методическим материалом для изучения цифровой схемотехники, основ Verilog и типовых конструкций FPGA.

### **1. Модули**

## 🔧 Аппаратные особенности MINI_FPGA

### **Тактовый сигнал**
Стандартно — 50 МГц (в зависимости от ревизии платы).

### **Сброс (RSTn)**
- Линия `RSTn` подключена к ползунковому переключателю **SW0**
- Активный уровень сброса — **низкий**
- **SW0 вниз → RESET (модуль в сбросе, горит только LED0)**  
- **SW0 вверх → RUN (огонёк работает)**

⚠ По схеме платы отсутствует полноценная цепь авто-сброса (POR).  
Поэтому по умолчанию **все ползунки должны стоять вверх (3.3V)**.

## 💡 Описание работы модуля `led8_module`

Модуль реализует:

### ✔ Циклический сдвиг вправо  
```verilog
rLED_Out <= {rLED_Out[0], rLED_Out[7:1]};
````

Создаёт бегущий огонёк из одной “единицы”.

### ✔ Таймер задержки (100 мс по умолчанию)

Счётчик считает до:

```
T100MS = 5_000_000 тактов ≈ 0.1 с при 50 МГц
```

Когда задержка истекает — выполняется сдвиг.

### ✔ Защита от ошибочного состояния

Если регистр случайно стал `0000_0000`, он автоматически восстанавливается.

---

## ⏱ Настройка скорости огонька

Чтобы получить смену светодиода **раз в 1 секунду**:

```verilog
parameter T1S = 26'd50_000_000;
```

## 🧩 Модуль `run_led`

Верхнеуровневый модуль, который подключает `led8_module` напрямую к топу:

```verilog
led8_module U1 (
    .CLK(CLK),
    .RSTn(RSTn),
    .LED_Out(LED_Out)
);
```

Используется в учебных проектах для простоты интеграции.
