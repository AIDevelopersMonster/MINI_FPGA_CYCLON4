# 📘 MINI_FPGA Cyclone IV — Полный учебный репозиторий

### Полный курс по цифровым системам, Verilog, периферии и реальным устройствам на FPGA

Этот репозиторий — систематизированная обучающая программа по разработке цифровых систем на базе FPGA **Cyclone IV EP4CE6F17C8**, использующей учебную плату **MINI_FPGA**.
Материалы собраны на основе методичек:

* 📄 *Методическое руководство по цифровым экспериментам с FPGA (MINI-FPGA)*
* 📄 *基于FPGA的数字实验指导书（MINI FPGA版）*
* 📄 *Прошивка программ через JTAG*
* 📄 *Принципиальная схема MINI_FPGA*

Цель проекта — шаг за шагом научить тебя создавать **реальные FPGA-проекты**, от первых логических схем до DDS-генераторов, UART-систем и цифровых часов.

---

# 🎯 Цели проекта

* Освоить **Verilog** от азов до структурного проектирования
* Научиться создавать проекты в **Quartus Prime**
* Понять принцип работы цифровых блоков: триггеры, счётчики, декодеры
* Научиться работать с периферией: LED, кнопки, индикаторы, buzzer, UART
* Использовать встроенные инструменты FPGA: **IP-ядра, PLL, ROM, SignalTap**
* Прошивать прошивки как временно (SOF), так и в SPI-Flash (JIC)
* Создавать законченные проекты:

  * цифровые часы
  * квиз-систему
  * DDS-генератор
  * PWM-модули
  * UART RX/TX
  * AD/DA обработку

# 🔌 Прошивка FPGA

## ✔ Временная загрузка (.SOF)

Не сохраняется после выключения питания.

```
Tools → Programmer
Add File (.sof)
Start
```

## ✔ Постоянная прошивка (.JIC)

Сохраняется в SPI-Flash, загружается при старте платы.

1. File → Convert Programming Files
2. Type: **JTAG Indirect Configuration (.jic)**
3. Device: **EPCS16**
4. Add Device → EP4CE6
5. Add File → ваш SOF
6. Generate
7. Programmer → выбрать JIC
8. Program/Configure → Start
